# Worked allergy example — Persona A

Same structured quiz as `Persona A`, plus `allergies: ["ashwagandha"]`.

**Baseline:** L-Theanine 400mg  ·  Magnesium (as Magnesium Malate) 400mg  ·  Ashwagandha Root Extract 200mg  ·  Taurine 1000mg  ·  Cordyceps Extract 2000mg  ·  Acetyl-L-Carnitine HCL 500mg  ·  Creatine (Creatine Monohydrate) 5000mg

**After allergy:** L-Theanine 400mg  ·  Magnesium (as Magnesium Malate) 400mg  ·  Taurine 1000mg  ·  Cordyceps Extract 2000mg  ·  Acetyl-L-Carnitine HCL 500mg  ·  Creatine (Creatine Monohydrate) 5000mg  ·  Alpha-GPC 300mg

Hard-blocked items:

- **Ashwagandha Root Extract** — HARD BLOCK — Allergy / avoid list match on `ashwagandha` → Ashwagandha Root Extract is excluded (hard filter). NOTE — Heavy / irregular periods are a clinician question (fibroids, thyroid, iron status). Ashwagandha is not a treatment for menorrhagia.
- **Caffeine** — HARD BLOCK — Caffeine blocked: sleep is a primary goal and the user already drinks 2 coffees/day. Adding catalog caffeine (100–300 mg) or caffeinated green tea extract fights the sleep goal.
- **Green Tea Extract (50% EGCG)** — HARD BLOCK — Green Tea Extract (50% EGCG) blocked: sleep is a primary goal and the user already drinks 2 coffees/day. Adding catalog caffeine (100–300 mg) or caffeinated green tea extract fights the sleep goal.
- **Vitamin D (Cholecalciferol)** — HARD BLOCK — Already taking a multivitamin (typically includes vitamin D). Catalog dose is 4000 IU — the IOM UL. Do not stack another 4000 IU on top without a 25-OH-D level and a plan.

Allergy / avoid-list tokens are hard exclusions. Scoring cannot put a matched active back into the sachet.
